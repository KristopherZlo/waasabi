# Sample post artwork

The README shows demonstration posts from a separate database.
The built-in imagegen tool created these covers. The interface images are captures of the running application.

## night-bus

Use case: photorealistic-natural. Asset type: panoramic cover for a demonstration photography post in a creative community README, not an interface screenshot. Primary request: a striking, believable documentary photograph through a city bus window late at night, rain beads on glass, blurred amber streetlights and cool teal reflections, a passing illuminated tram at the far side, subtle analog film grain. Wide cinematic 21:9 horizontal composition, 1800x800 if possible. Quiet urban atmosphere, strong composition, deep charcoal shadows with warm copper highlights. No text, no brands, no watermark, no UI, no collage, no faces in focus.

## pocket-garden

Use case: stylized-concept. Asset type: panoramic cover artwork for a demonstration indie game post in a creative community README, not an interface screenshot. Primary request: a polished isometric indie game environment: one small overgrown stone courtyard suspended as a diorama, moss-covered steps, fern patches, a tiny weathered archway, little glowing pale flowers. Handmade low-poly forms with detailed soft textures, rendered like an independent game's art portfolio. Sage and vivid leafy greens, warm pale stone, quiet peach highlights, dark forest background. Wide cinematic 21:9 horizontal composition, 1800x800 if possible. Beautiful readable silhouette and material detail. No text, no UI, no watermarks, no characters, no collage.

## looper

Use case: product-mockup. Asset type: panoramic cover for a demonstration open-source music hardware project in a creative community README, not an interface screenshot. Primary request: a carefully made prototype audio looper pedal on a dark studio workbench, brushed aluminum rectangular enclosure, four large tactile amber-orange pads, two black rotary knobs, exposed tiny screws, an audio cable trailing away, printed circuit board and screwdriver slightly out of focus nearby. Side angle close-up with tangible materials and soft directional studio light. Charcoal, silver, copper and orange, restrained realistic industrial design. Wide cinematic 21:9 horizontal composition, 1800x800 if possible. No labels or text, no brands, no watermarks, no UI, no collage.
