# Profile settings and theme

## Profile settings
The profile settings page lets you manage:
- Account overview (name, email, role, ID).
- Profile info (name and bio). Avatar and banner are edited from the profile page.
- Privacy settings: share activity, allow mentions, personalized recommendations.
- Notification toggles: comments, reviews, follows.
- Connections: allow followers and show follower counts.
- Devices: login alerts.
- Support: quick link to the support portal.

## Theme switching
Use the quick settings menu in the top bar to choose Dark, Light, or System. The choice is stored locally and applied across the site.
